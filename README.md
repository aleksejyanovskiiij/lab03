# Лабораторная работа 3 - Визуализация данных

Решение лабораторной работы по визуализации данных с использованием библиотек
**Pandas**, **Matplotlib** и **Seaborn** на языке Python.

## Цель работы

Освоить методы разведочного анализа данных (EDA): визуализацию распределений,
выявление трендов, зависимостей между переменными, а также обнаружение пропусков
и аномалий.

## Задачи

1. Провести первичный анализ структуры данных.
2. Вычислить основные статистические характеристики.
3. Построить визуализации распределений признаков.
4. Выявить тренды и зависимости между переменными.
5. Обнаружить пропуски и аномалии.

## Набор данных

`StudentsPerformance.csv` содержит информацию об успеваемости студентов и
содержит 1000 строк и 8 столбцов:

| Столбец | Описание |
| --- | --- |
| `gender` | Пол студента (`male` / `female`) |
| `race/ethnicity` | Этническая группа (group A–E) |
| `parental level of education` | Уровень образования родителей |
| `lunch` | Тип питания (standard / free/reduced) |
| `test preparation course` | Прохождение подготовительного курса |
| `math score` | Баллы по математике (0–100) |
| `reading score` | Баллы по чтению (0–100) |
| `writing score` | Баллы по письму (0–100) |

## Что делает скрипт

### Разведочный анализ данных через Pandas

- Размер набора данных, первые строки, структура (`df.info()`).
- Основные статистические характеристики (`df.describe()`).
- Количество пропусков по столбцам (`df.isnull().sum()`) - в данном наборе
  пропусков нет.
- Количество уникальных значений по столбцам (`df.nunique()`).
- Анализ выбросов для `math score` по правилу IQR (межквартильного размаха).

### Визуализация средствами Pandas

1. **Столбчатая диаграмма** для столбца `parental level of education`.
2. **Круговая диаграмма** для столбца `race/ethnicity`.
3. **Гистограммы** для всех числовых столбцов.

### Визуализация средствами Matplotlib (subplots 3×2)

| Позиция | Содержимое |
| --- | --- |
| (1,1) | Графики функций **y1 = cos(2x)** (жёлтый) и **y2 = 2cos(x)** (красный), x в [−2pi, 2pi], с сеткой |
| (1,2) | **«Ящик с усами»** для `math score` - проверка наличия выбросов |
| (2,1) | Комбинированная **столбчатая диаграмма + график** для `race/ethnicity` |
| (2,2) | **Текстовый вывод** «HELLO!!!» |
| (3,1) | **3D-диаграмма рассеяния** для `math score`, `reading score`, `writing score` |
| (3,2) | **Круговая диаграмма** (с %) для `parental level of education` только для юношей (`gender = male`) |

### Визуализация средствами Seaborn

1. **`pairplot`** для числовых столбцов - гистограммы по диагонали и диаграммы
   рассеяния.
2. **`pairplot`** с `diag_kind="kde"` и кластеризацией по полу (`hue="gender"`).
3. **Тепловая карта** корреляций числовых столбцов (`sns.heatmap`).

## Результаты / выводы

- Пропусков в данных нет.
- По правилу IQR для `math score` обнаружены нижние выбросы, то есть несколько
  студентов с аномально низкими баллами.
- Наблюдается сильная положительная корреляция между баллами по чтению и письму
  (и умеренная между математикой и остальными предметами).
- Средние баллы имеют заметные различия в зависимости от образования родителей и
  этнической группы.
